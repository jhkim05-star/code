# 책꽂이 · 기록

읽는 책과 읽은 책, 본 영화·드라마를 남기는 개인용 독서·감상 노트입니다.
아이폰 사파리에서 홈 화면에 추가해 앱처럼 쓰도록 만들었습니다.
빌드 도구·서버·계정 없이 정적 파일만으로 동작하며, 기록은 기기 안에만 저장됩니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| **책꽂이** | 읽는 중 · 읽을 예정 (썸네일 격자, 상태 배지) |
| **책장** | 완독한 책 (연도별 묶음, 썸네일에 별점 표시) |
| **비디오장** | 본 영화·드라마 시리즈 (월별 묶음) |
| **통계** | 월별 / 주별 추이, 장르·한국외국·형식 분포 |
| **설정** | 썸네일 크기, 엑셀·CSV·JSON 내보내기, 백업 복원 |

### 기록 흐름

```
[+] → 제목 입력 → 표지·저자·출판사 자동 조회 → 필요한 곳 수정 → 저장
                                 ↓
          책꽂이(읽을 예정) ──[읽기 시작]──▶ 책꽂이(읽는 중, D+n)
                                                    │
                                              [다 읽음]
                                                    ▼
                              책장 (읽은 기간 자동 산출 + 별점·한줄평 입력)
```

- **읽기 시작**을 누르면 시작 날짜와 시각(`startedTime`)을 함께 기록하고 `읽는 중` 배지에 경과일(D+n)을 표시합니다.
- **다 읽음**을 누르면 완독일을 기록하고 `읽은 기간(일)`을 산출한 뒤 자동으로 책장으로 옮깁니다. 이어서 별점·한줄평·독서록을 남기는 창이 뜹니다.
- 썸네일을 누르면 읽은 날짜, 읽은 기간, 별점, 한줄평, 독서록, 종이책 여부를 한 화면에서 봅니다. 책꽂이·책장·비디오장 모두 같은 방식입니다.

## 시작하기

정적 파일이라 웹서버로 열기만 하면 됩니다.

```bash
# 아무 정적 서버나 사용 가능
npx http-server -p 8123 .
# 또는
python3 -m http.server 8123
```

브라우저에서 `http://localhost:8123/index.html` 로 접속합니다.

### 아이폰에 설치

1. 같은 네트워크의 PC에서 위 서버를 띄우거나, GitHub Pages 등에 이 저장소를 **HTTPS로** 올립니다.
2. 아이폰 사파리로 접속 → 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 뜨고, 서비스워커가 앱 파일을 캐시해 오프라인에서도 열립니다.

> 표지 자동 조회와 표지 이미지 로딩은 인터넷 연결이 필요합니다.
> HTTPS 로 서비스해야 표지 이미지가 차단되지 않습니다(혼합 콘텐츠 차단).

## 데이터 저장

- 모든 기록은 브라우저 `localStorage` 의 `bookshelf.data.v1` 키에 저장됩니다. 서버로 나가는 개인 기록은 없습니다.
- 기기를 바꾸거나 사파리 데이터를 지우면 사라집니다. **설정 → JSON 백업 내보내기**로 주기적으로 받아두세요.
- 복원은 **설정 → JSON 백업 불러오기**에서 `합치기` / `덮어쓰기` 중 선택합니다.

## 표지·정보 자동 조회

| 구분 | 1순위 | 2순위 | API 키 |
|---|---|---|---|
| 책 | Google Books API | Open Library | 불필요 |
| 영상 | iTunes Search API | — | 불필요 |
| 영상(선택) | TMDB | iTunes | 설정에서 입력 |

- 제목을 입력하고 잠시 멈추면 자동으로 조회하고, `찾기` 버튼으로도 즉시 조회합니다. ISBN 을 넣어도 됩니다.
- 가져온 값은 전부 폼에서 수정할 수 있고, 표지는 직접 URL 을 넣거나 사진 앨범에서 고를 수도 있습니다(가로 420px 로 줄여 저장).
- 브라우저에서 직접 호출하며 CORS 가 막히는 환경(`file://` 등)에서는 JSONP 로 자동 전환합니다.
- Google Books 는 프로젝트 없이 쓰면 일일 조회 한도가 있어 실패할 수 있습니다. 실패 시 Open Library 로 넘어가고, 그래도 안 되면 직접 입력하면 됩니다.
- TMDB 키를 넣으면 한글 제목·장르 정확도가 올라갑니다. 키는 이 기기에만 저장됩니다.

## 내보내기

**설정 → 내보내기**에서 받습니다.

- **엑셀(.xlsx)** — 4개 시트
  - `책` : 상태·제목·저자·출판사·ISBN·페이지·장르·한국외국·종이책여부·별점·시작일·완독일·읽은기간·한줄평·독서록
  - `비디오장` : 종류·제목·감독·장르·제작국가·러닝타임·편수·총 시청시간·플랫폼·별점·본 날짜·한줄평·감상평
  - `기간별 통계` : 최근 12개월 + 최근 12주 집계
  - `분포` : 장르 / 한국외국 / 형식 / 저자 / 플랫폼 집계
  - 머리글 고정과 자동 필터가 걸린 상태로 열립니다.
- **CSV** — 독서 기록 / 영상 기록 각각. BOM 을 붙여 엑셀에서 한글이 깨지지 않습니다.
- **JSON** — 전체 백업/복원용.

엑셀 파일은 외부 라이브러리 없이 `assets/js/xlsx.js` 에서 ZIP + OOXML 을 직접 만들어 씁니다(CDN 의존성 없음).

## 통계 항목

- 이번 달·이번 주 요약: 완독 권수, 읽은 페이지, 본 영상 편수, 시청 시간, 평균 별점, 평균 독서 기간
- 월별/주별 추이: 책(레드)·영상(블루) 누적 막대. 막대를 누르면 그 구간만 분석하고, `숫자로 보기`로 표를 펼칩니다.
- 분포: 책 장르 / 한국·외국 / 종이책 여부, 영상 장르 / 한국·외국, 시청 플랫폼, 많이 읽은 저자
- 전체 기록: 누적 완독 권수·페이지, 누적 시청 편수·시간, 읽는 중·읽을 예정 권수

## 디자인

- 검정 바탕 · 흰 글씨, 포인트는 글로시 레드(`#ff375f`)와 블루(`#0a84ff`).
- 두 포인트 색은 색각이상 조건에서도 구분되도록 검증한 조합입니다(OKLab ΔE 23.9 protan / 38.1 정상시). 통계 그래프에서 색만으로 구분하지 않도록 범례와 숫자를 함께 표시합니다.
- 썸네일 격자는 아이폰 세로 기준 **가로 4개**가 기본이고, 설정에서 **가로 3개(크게)** 로 바꿀 수 있습니다. 홈 화면에서 전체 화면으로 실행하면 한 화면에 4~5줄이 들어옵니다.

## 파일 구조

```
index.html                 화면 뼈대
manifest.webmanifest       홈 화면 추가(PWA) 설정
sw.js                      오프라인 캐시(앱 파일만, 외부 요청은 통과)
assets/css/app.css         디자인 토큰과 전체 스타일
assets/js/util.js          날짜·주차·포맷 등 공용 함수
assets/js/store.js         데이터 모델, localStorage, 장르 분류표
assets/js/api.js           Google Books / Open Library / iTunes / TMDB 조회
assets/js/xlsx.js          의존성 없는 XLSX(엑셀) 작성기
assets/js/stats.js         월별·주별 집계
assets/js/ui.js            썸네일·상세·입력폼·바텀시트
assets/js/views.js         통계 화면, 설정 화면, 내보내기
assets/icons/              앱 아이콘
```

## 개발 메모

- 프레임워크·빌드 단계 없음. 클래식 `<script>` 로만 불러오므로 `file://` 로 열어도 대부분 동작합니다(서비스워커 제외).
- 상태 변경은 모두 `Store` 를 거치고, 저장 후 `UI.render()` 로 화면을 다시 그립니다.
- 바텀시트는 열 때마다 내부 컨테이너를 새로 만듭니다. `innerHTML` 만 갈아끼우면 이전 시트의 클릭 핸들러가 남아 다른 책에 `다 읽음`이 적용되는 문제가 생깁니다.
