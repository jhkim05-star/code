# 운동일지

혼자 하는 웨이트를 위한 **계획 · 실행 · 기록** 앱.
아이폰 사파리에서 열고 홈 화면에 추가하면 앱처럼 전체 화면으로 뜹니다.

빌드 도구도 서버도 없습니다. 정적 파일뿐이라 GitHub Pages에 올리면 그대로 돌아갑니다.

---

## 무엇을 하는 앱인가

**계획** — 가슴/등 2분할에 일요일 하체를 붙인 루틴을 자동으로 짭니다.
가슴 날에는 어깨 전면과 삼두를, 등 날에는 어깨 측후면과 이두를 함께 합니다
(미는 동작끼리, 당기는 동작끼리 묶여 어깨와 팔이 중복으로 지치지 않습니다).
같은 부위를 주 2회 하되 **두 번의 종목 구성이 겹치지 않고**, 주가 바뀌면 종목 풀이
한 칸씩 밀려 매주 조금씩 달라집니다. 요일 배치는 설정에서 바꿀 수 있습니다.

**AI 계획** — "이번 주는 어깨가 아파서 프레스는 빼 주세요", "벤치가 3주째 안 올라가요"처럼
사정을 적어 주면 Claude가 최근 기록과 고정 루틴을 함께 보고 한 주를 다시 짭니다.

**실행** — 오늘의 계획을 종목 순서대로 진행합니다. 횟수를 음성으로 세 주고,
**세는 속도와 휴식 시간을 운동 중에 슬라이더로 바로 바꿀 수 있습니다.**
세트가 끝나면 휴식 타이머가 자동으로 돌고, 끝나기 10초 전에 알려 줍니다.

**기록** — 종목별 무게·횟수가 전부 남습니다. 주간 볼륨 추이, 부위별 볼륨,
종목별 최고 기록을 통계에서 봅니다. 다음 주 계획을 만들 때 이 기록이 자동으로 반영됩니다.

## 쓰기 시작하기

### 1. 웹에 올리기 (아이폰에서 쓰려면 필요)

가장 간단한 방법은 GitHub Pages입니다.

1. 이 저장소 → **Settings → Pages**
2. Source를 **Deploy from a branch**, 브랜치를 `main`(또는 이 브랜치), 폴더를 `/ (root)` 로 지정
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다

> HTTPS여야 합니다. 음성·화면꺼짐방지·오프라인 캐시가 모두 보안 연결에서만 동작합니다.

### 2. 홈 화면에 추가

아이폰 사파리에서 주소를 연 뒤 **공유 → 홈 화면에 추가**.
주소창 없이 전체 화면으로 뜨고, 오프라인에서도 열립니다
(AI 계획 생성만 인터넷이 필요합니다).

### 3. 내 컴퓨터에서 열어 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 직접 열면 브라우저 보안 정책 때문에 동작하지 않습니다. 반드시 서버로 띄우세요.

### 4. AI 계획을 쓰려면

1. [console.anthropic.com](https://console.anthropic.com) → API Keys 에서 키 발급
2. 앱의 **설정 → AI 계획**에 붙여넣고 "키 확인하기"

키는 이 기기에만 저장되고, 계획을 만들 때 anthropic.com 으로만 전송됩니다
(중간 서버가 없어서 키를 맡길 곳도 없습니다).
계획 한 번 만드는 데 Opus 5 기준 100원 안팎, Sonnet 5 기준 40원 안팎입니다.

## 알아 둘 것

**화면은 켜 둔 채로 쓰세요.** 아이폰 사파리는 화면이 꺼지면 음성이 끊깁니다.
앱이 운동 중에는 화면 꺼짐 방지를 걸어 두지만(설정에서 끌 수 있음),
폰을 주머니에 넣고 쓰는 용도로는 맞지 않습니다. 거치대에 두고 쓰는 걸 권합니다.

**기록은 이 기기 안에만 있습니다.** 브라우저 데이터를 지우거나 폰을 바꾸면 사라집니다.
가끔 **설정 → 데이터 → 백업 내보내기**로 JSON 파일을 받아 두세요. 새 기기에서는
같은 화면의 "불러오기"로 복원합니다.

**첫 화면을 한 번 눌러야 소리가 납니다.** iOS는 사용자가 화면을 건드리기 전에는
소리를 못 내게 막습니다. 운동 화면에 들어가는 순간 자동으로 처리되니 신경 쓸 일은 없습니다.

## 목소리 바꾸기

기본은 기기에 내장된 한국어 음성(아이폰은 보통 '유나')이고,
설정 → 음성에서 **음 높이**를 올려 밝은 톤으로 맞출 수 있습니다.

직접 녹음하거나 만든 음성 파일로 통째로 바꿀 수도 있습니다.
파일을 `audio/` 에 넣고 `audio/manifest.json` 에 등록하면 됩니다.
숫자만 먼저 넣고 나머지는 나중에 채워도 되고, 등록되지 않은 것은 내장 음성이 읽습니다.
규격은 [`audio/README.md`](audio/README.md)에 있습니다.

## 구조

```
index.html            앱 껍데기
manifest.webmanifest  홈 화면 추가용
sw.js                 오프라인 캐시
css/app.css           클래식 운동일지 테마 (다크 모드 포함)
js/
  app.js              부팅 · 해시 라우팅 · 탭바
  store.js            저장소 (IndexedDB, localStorage 폴백) · 백업/복원
  exercises.js        운동 종목 DB (부위 8분류, 70여 종목)
  planner.js          규칙 기반 주간 계획 생성 (A/B 로테이션)
  ai.js               Claude Messages API 호출 · 계획 JSON 스키마
  runner.js           운동 실행 상태 머신 (카운트 · 휴식 타이머)
  voice.js            한국어 수사 · 오디오 클립/TTS 2단 구조
  ui.js               DOM 헬퍼 · 모달 · 토스트
  util.js             날짜 · 포맷
  views/              plan · run · history · stats · settings
audio/                음성 교체용 (기본은 비어 있음)
```

프레임워크도 의존성도 없습니다. 브라우저의 ES 모듈만 씁니다.

## 루틴 규칙을 바꾸고 싶다면

**설정 → 루틴**에서 요일별 배치(가슴 / 등 / 하체 / 휴식)와 A·B 구분을 바꿀 수 있습니다.
하루에 몇 종목씩 할지 같은 더 깊은 규칙은 `js/planner.js` 위쪽의 `DAY_TEMPLATES` 를
고치면 됩니다.

```js
push: { label: '가슴', groups: [
  { group: 'chest',   count: 3 },   // 가슴 3종목
  { group: 'delt_f',  count: 2 },   // 어깨 전면 2종목
  { group: 'triceps', count: 2 },   // 삼두 2종목
]},
```

하는 운동이 목록에 없으면 **설정 → 내가 추가한 종목**에서 추가하세요.
자동 생성과 AI 생성 모두 추가한 종목을 후보로 씁니다.
