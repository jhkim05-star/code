# 주기 사용내역 · 빠른 입력 (1.7.0)

## 사용 흐름

홈의 남은 예산 영역을 `이번 주기 사용내역`으로 교체합니다. 기준은 오늘을 포함하는 사용기간이 아니라 선택한 **결제월**입니다. 기본 결제월은 설정 시간대의 이번 달입니다. 예산과 월별 통계, 카드 결제 예정 화면의 기존 의미는 바꾸지 않습니다.

큰 `이번 주기 지출` 금액 → 카드별 금액 / 카드 합계 / 현금·계좌 고정지출 / 일반지출 / 합계 / 특이사항을 봅니다. 각 금액에서 실제 포함 내역으로 들어가 수정할 수 있습니다. 홈과 상세는 동일한 entries 합계를 사용합니다.

- 카드별 기존 사용기간을 재사용합니다. 기간이 다르면 각 카드 옆에 실제 범위를 표시합니다.
- 비활성 카드도 해당 주기에 거래가 있으면 포함합니다. 이름이 같아도 ID로 구분합니다.
- 현금·계좌는 최초에 달력월(1일~말일) 기준입니다. `기간 설정`에서 전월 시작일~당월 종료일을 직접 설정할 수 있습니다. 카드 기간을 임의로 추정하지 않습니다.
- 카드와 현금 기간 변경에는 적용 시작 결제월이 있습니다. 이전 월 설정을 보존하고, 기간이 겹치거나 비는 경우 안내합니다. 카드 기간은 이번 결제월 또는 이전 월부터 적용할 수 있습니다.
- 결제일이 지나도 사용내역 총액은 0원으로 바뀌지 않습니다. 아직 발생하지 않은 예상 고정지출과 이체는 제외합니다.
- 기존 할부는 현재 계산기의 해당 회차분을 사용하고 취소는 입력된 날짜에 음수로 반영합니다. 환급 때문에 합계가 음수여도 숨기지 않습니다. 카드사 청구서 자체와 동일하다는 보장은 하지 않습니다.
- 연결되지 않은 카드와 해석할 수 없는 카드 기간은 합계에서 제외하고 **전체 미분류 내역**으로 명시합니다. 특정 결제월에 임의 배정하지 않습니다.

## 빠른 입력

시간 입력을 제거했습니다. 기존 시간 필드는 호환성을 위해 신규 입력 시 설정 시간대의 입력 시각을 자동 기록하며 기존 거래 시간은 변경하지 않습니다.

카테고리는 금액이 아닌 누적 거래 횟수 내림차순입니다. 같은 횟수면 최근 사용일, 그다음 기존 순서를 유지합니다. 취소·예상 거래·미래 날짜·다른 거래 유형은 순위 계산에서 제외합니다. 작성 도중 목록을 재정렬하지 않습니다.

`설정 → 카드와 결제주기 → 카드할부 사용`은 기본 꺼짐입니다. 켠 경우에만 카드 지출에서 할부 입력이 보입니다. 현금·계좌·이체로 바꾸면 입력을 숨기고 비활성화하며 숨은 값이 저장되지 않습니다. 설정을 꺼도 이미 저장된 할부는 보존합니다. 기존 할부 수정 화면에서는 설정이 꺼져 있으면 읽기 안내만 표시합니다.

## 데이터 보호

DB/schema 버전을 올리거나 시작 시 기존 스냅샷을 새로 쓰지 않습니다. 새 필드가 없는 구버전은 그대로 읽습니다. 설정은 `settings.installmentsEnabled`, `settings.cashCycleHistory`, 카드의 `cycleHistory`, 특이사항은 `meta.cycleNotes[결제월]`에 명시적 저장 시 추가됩니다.

특이사항은 거래와 별개이며 금액을 적어도 합계가 바뀌지 않습니다. 기존 revision 비교와 저장 성공 후 메모리 교체를 유지하고, 메모 충돌·저장 실패 시 입력과 이전 저장본을 보존합니다.

앱의 전체 JSON 백업은 거래·카드·예산·설정·기간 이력·특이사항을 함께 복원합니다. 미리보기와 별도 전체 교체 확인이 필요하며 기존 데이터는 저장소의 복원 전 사본에 보관합니다. 백업의 revision을 현재 저장소에 채택하지 않습니다. 일반 거래 배열 가져오기와 Notion 가져오기는 기존 경로를 유지합니다.
