# 기존 녹음 음성 보존·교체

`manifest.json`의 `voice: "내사랑"`과 `count.1`~`count.30` 경로를 유지했습니다. 이 수정 묶음에는 실제 MP3 파일을 넣지 않았습니다. **기존 `audio/ko-user/*.mp3`를 삭제하거나 새 빈 폴더로 교체하지 마세요.**

재생은 Web Audio에서 디코딩한 클립 우선, 없거나 읽지 못하면 기기 TTS 순서입니다. 하나의 오디오 컨텍스트와 취소 세대를 사용하므로 이전 카운트의 늦은 다운로드/재생 실패가 이후 상태에서 갑자기 말하지 않도록 했습니다. 사용자 동작 안에서 오디오를 준비하고, 화면을 가리거나 실행을 일시정지하면 재생·예약을 취소합니다.

클립은 앱 내부 `audio/` 경로의 MP3/M4A/WAV/OGG 파일로 등록합니다. 숫자 파일은 짧고 앞뒤 무음이 적어야 합니다. 녹음 클립의 발음 자체는 숫자 스타일·TTS 목소리·TTS 피치 설정으로 바뀌지 않습니다. 볼륨은 재생 gain으로 적용합니다.

없는 숫자·안내는 TTS로 읽습니다. 휴식 경고값이 10초가 아니면 ‘십 초’ 녹음을 재사용하지 않고 설정에 맞는 문장을 만듭니다. 오프라인 클립 캐시는 선택 사항이므로 다운로드가 누락될 수 있으며, 기기의 내장 음성 가용성도 실제 기기 확인이 필요합니다.

서버 코드와 모의 테스트만으로 아이폰 스피커에서 실제 소리가 났다고 검증할 수는 없습니다. 홈 화면 앱에서 첫 터치, 화면 잠금·복귀, 카운트 간격, 알림과 통화에 따른 중단을 확인해 주세요. 설정의 들어보기·오디오 진단을 사용할 수 있습니다.
