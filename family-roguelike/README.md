# 가족 로그라이크 — Level 3

Phaser 4 + TypeScript + Vite로 만든 5층 미니 런입니다. 전투에서 이기면 카드 3장 중 1장을 고르거나, 덱의 카드 1장을 강화·제거할 수 있습니다. 잽과 연속타, 방어와 받아치기, 중독과 독 증폭으로 서로 다른 플레이 방식을 시험할 수 있습니다. 체력과 덱은 층 사이에 유지되고, 5층 보스를 이기면 런이 끝납니다. 최고 도달 층만 이 브라우저에 저장됩니다. 맵·상점·이벤트·아트·사운드는 아직 없습니다.

중독은 적 턴 시작에 현재 수치만큼 피해를 주고 1 줄어듭니다. 받아치기의 반격은 적 공격 후 살아 있을 때 적용됩니다. 보상 후보는 중복 없이 3장 나오며 희귀도가 높은 카드는 덜 자주 나옵니다. 진행 중인 런 자체는 새로고침 후 복원되지 않습니다.

```sh
npm install
npm run dev
npm test
npm run build
```

개발 서버 주소는 터미널에 표시됩니다. 가로 화면을 기준으로 960×540 게임 영역 전체가 화면 안에 맞춰집니다. 세로 화면에서도 영역을 자르지 않고 축소해 보여주므로 글자가 작아질 수 있습니다.

Vite 빌드는 상대 자산 경로를 사용하므로 `/code/family-roguelike/` 같은 GitHub Pages 하위 경로에서도 작동합니다. 배포할 때는 `dist/`의 내용을 해당 경로에 게시해야 합니다.

이 저장소의 Pages 작업은 게임을 빌드한 다음 `dist/`만 `/code/family-roguelike/`에 게시합니다. 기존 정적 앱의 파일은 그대로 유지합니다.
