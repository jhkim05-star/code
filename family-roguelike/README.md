# 밤의 거실 — 가족 로그라이크 Chapter 1

Phaser 4 + TypeScript + Vite로 만든 가족용 1인 카드 덱빌딩 게임입니다. 담요 망토를 두른 주인공이 밤의 거실을 지나 잠꾸러기 왕에게 도전합니다. 카드 전투와 층별 경로 선택의 익숙한 흐름에, 집안 물건을 적과 기술, 사건으로 사용했습니다.

## 플레이

- 12층에서 전투, 강적, 사건, 휴식, 상점을 골라 진행합니다. 마지막 층은 보스전입니다.
- 전투마다 에너지 3과 손패 최대 5장으로 공격, 방어, 중독, 반격 카드를 사용합니다. 적의 다음 행동은 화면에 표시됩니다.
- 전투 뒤 카드 획득, 강화, 제거 중 하나를 고를 수 있습니다. 체력과 덱, 금화는 층 사이에 유지됩니다.
- 진행 중인 원정과 최고 도달 층은 현재 브라우저에 자동 저장됩니다. 다른 기기와 기록이 동기화되지는 않습니다.
- 소리는 오른쪽 위 버튼으로 끌 수 있습니다. 음악 대신 짧은 조작 효과음만 사용합니다.

## 개발

```sh
npm install
npm run dev
npm test
npm run build
```

게임 화면은 960×540 비율로 만들어졌습니다. 휴대전화는 가로 방향을 권장하며, 세로 방향에서도 전체 영역을 축소해 보여줍니다. Vite의 상대 경로 설정 덕분에 GitHub Pages의 `/code/family-roguelike/`에서 실행됩니다. 저장소의 Pages 작업은 게임 빌드 결과만 해당 하위 경로에 게시합니다.

이 버전은 Chapter 1을 처음부터 끝까지 플레이할 수 있는 첫 완성판입니다. 카드 수치와 실제 플레이 시간은 가족 플레이 후 조정할 수 있습니다. 가족 구성원의 구체적인 특징이나 내부 농담은 아직 넣지 않았습니다.
