# 가족 로그라이크 — Level 1

Phaser 4 + TypeScript + Vite로 만든 전투 프로토타입입니다. `family-roguelike/`를 잇는 후속작이 아니라, 같은 계획을 바탕으로 새로 독립 구성한 폴더입니다.

```sh
npm install
npm run dev
npm run build
```

개발 서버 주소는 터미널에 표시됩니다. 가로 화면을 기준으로 960×540 게임 영역 전체가 화면 안에 맞춰집니다(Phaser Scale Manager `FIT` + `CENTER_BOTH`).

## 구조

```
src/
├─ main.ts              Phaser 부팅, Scene 등록
├─ scenes/
│   └─ BattleScene.ts   화면 표시·입력·연출만 담당
└─ game/
    ├─ combat.ts         전투 규칙(카드 사용 → 에너지 감소 → 적 HP 감소 등). Phaser를 참조하지 않는 순수 로직
    ├─ cards.ts           카드 정의 + 드로우/버린 더미를 오가는 카드 인스턴스
    └─ enemies.ts         적 정의 + 다음 행동(의도) 계산
```

`game/`은 규칙, `scenes/`는 화면. 나중에 밸런스를 바꿀 때 Phaser 코드를 뒤질 필요가 없도록 처음부터 이 둘을 분리했습니다.

## Level 1 성공 조건 (완료)

1. 브라우저에서 게임이 열린다.
2. iPhone / iPad / Galaxy 크기에서 화면이 잘리지 않는다.
3. 플레이어 HP가 표시된다.
4. 적 HP가 표시된다.
5. 에너지 3으로 턴이 시작된다.
6. 덱에서 카드 5장이 나온다.
7. 공격 카드를 누르면 적에게 피해가 간다.
8. 방어 카드를 누르면 방어도가 생긴다.
9. 턴 종료 시 적이 행동하고 다음 턴이 시작된다.
10. 적 HP가 0이면 승리, 플레이어 HP가 0이면 패배한다.

덱은 공격 5장 + 방어 5장(총 10장)이며, 드로우 더미가 떨어지면 버린 더미를 섞어 다시 드로우 더미로 씁니다. 적은 1종(HP 40, 매 턴 공격 6)입니다.

## Level 1에 의도적으로 없는 것

카드 희귀도, 상태이상, 상점, 이벤트, 맵, 보스, 아이템, 가족 캐릭터, 카드 강화, 계정, 클라우드 저장, PWA, 음악, 정식 아트, 카드 드래그, 데미지 숫자 연출. 이후 아이디어는 `IDEAS.md`에 쌓고, 지금 Level의 성공 조건에 필요한 것만 구현합니다.
