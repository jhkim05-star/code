# 책꽂이 · 기록 — 독서 전용 1차 개편

하단 세 탭: 책꽂이 / 책장 / 노트. 비디오 기능·모델·영상 통계·설정은 제거했습니다.
HTML/CSS/ES Modules, 빌드 단계·외부 UI 라이브러리 없음.

## 실행
저장소 루트에서 `python3 -m http.server 8124` 후 `http://localhost:8124/reading/`.
`file://`는 ES 모듈을 실행하지 못합니다. 배포는 기존 GitHub Pages 경로를 유지합니다.

## 기록 흐름
제목 검색 또는 직접 입력 → 책꽂이 → 읽기 시작 → 완독일·별점·한줄평 → 책장.
긴 감상평은 별도 노트 화면에서 작성합니다. 모든 항목은 선택이고 입력을 멈추면 자동 저장합니다.
감상평은 핵심 내용 / 내 생각 / 나에게 남은 것 + 질문·적용을 지원합니다.
읽는 중 메모는 생각 / 인용 / 질문 / 해볼 일로 구분하고 페이지와 해석을 분리합니다.

## 데이터
- v2는 IndexedDB `bookshelf-reading`의 `kv`, `drafts`를 사용합니다.
- 책·독서 회차·노트는 ID로 연결합니다. 다시 읽어도 이전 완독 이력은 지우지 않습니다.
- 기존 `bookshelf.data.v1`은 최초 한 번 읽어 책만 이관합니다. 기존 독서록은 원문 보존.
- 성공적으로 이관한 뒤 이전 localStorage 키를 제거합니다. DB에는 책만 담은 이전 원본을 보존합니다.
- 초기 데이터가 손상됐거나 저장소 접근이 실패하면 빈 데이터로 덮어쓰지 않습니다.
- 브라우저 저장은 영구 백업이 아닙니다. 설정에서 JSON을 내보내 실제 파일을 확인하세요.
- 기기 간 자동 동기화·가족 계정 공유는 없습니다. 각 기기에 독립적으로 저장합니다.
- API 키는 JSON 백업에 포함하지 않습니다. 설정에 입력한 카카오 프록시와 알라딘 키는 기기 내부에만 저장합니다.

## 소스 구분
- `domain.js`: 순수 모델·날짜·이관·검증·통계. DOM/저장소 비의존.
- `repository.js`: 검증 후 원자적으로 저장, 노트 충돌 검사.
- `storage.js`: 브라우저 IndexedDB 어댑터. 기본 저장소를 임의 폴백하지 않습니다.
- `platform.js`: 저장소·파일 내보내기의 기기 경계. 추후 네이티브 저장소 어댑터 주입 가능.
- `views-books.js`: 책꽂이·책장·간단 기록·통계.
- `views-notes.js`: 노트 검색·읽기·자동 저장 편집기.
- `views-settings.js`: 백업·복원 미리보기·설정.
- `api.js`: 책 검색만. 카카오 → 기존 알라딘(설정된 경우만) → Google Books → Open Library.
- `exports.js`: JSON, Markdown, CSV, XLSX. 긴 글은 Excel 셀 한도 초과 시 원문을 자르지 않고 오류로 알립니다.

## 범위와 제한
이번 결과는 브라우저 검증용 앱입니다. iOS/Android 네이티브 바이너리가 아닙니다.
향후 Capacitor 등으로 정적 리소스를 앱 안에 묶고 SQLite·네이티브 파일 공유 어댑터를 붙이는 경로를 고려합니다.
서명·배포·실기기 음성/키보드/백업 검증은 별도 단계입니다.
기존 카카오 Worker 배포 파일은 이 변경에 포함하지 않으며 현재 주소를 그대로 사용합니다.
