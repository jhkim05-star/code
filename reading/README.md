# 책꽂이 — 개인 독서 서재

책등·북마크·열린 책을 모티프로 한 독서 기록 PWA입니다. 하단 메뉴는 책꽂이 / 책장 / 노트 / 통계 / 설정이며, 빨강·분홍·파랑·녹색·노랑 강조색과 블랙·베이지·화이트 배경을 서로 독립적으로 기기에 저장합니다. 빌드 단계나 외부 UI·차트 라이브러리는 사용하지 않습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8124`를 실행하고 `http://localhost:8124/reading/`을 엽니다. `file://`에서는 ES 모듈을 실행할 수 없습니다.

## 기록과 탐색

- 책꽂이에서 새 책을 등록하고 읽는 중인 책을 관리합니다.
- 책장에서는 완독·보관된 책과 컬렉션, 시리즈, 같은 작가 묶음을 탐색합니다.
- 종이책·전자책·오디오북은 표지 아이콘과 테두리·패턴을 함께 사용해 구분합니다.
- 감상평은 핵심 내용 / 내 생각 / 남은 질문 / 해볼 일로 기록하며 자동 저장과 오래된 편집 충돌 보호를 유지합니다.
- 통계는 재독을 책 한 권으로 집계하고 연도·월·평점·장르·출처·책유형·작가 분포를 CSS 그래프로 보여 줍니다. 막대를 누르면 해당 책 목록과 상세 화면으로 이동할 수 있습니다.
- 연도·월 통계와 통계 상세 책 목록은 최근 기록부터 보여 줍니다.
- 기존 책의 정보 수정 화면에서도 ISBN 또는 제목으로 다시 검색해 서지 정보와 표지를 갱신할 수 있습니다.

## Bookmory Excel

설정에서 Bookmory의 `책 목록` 시트와 2단 헤더 형식을 그대로 가져오거나 내보냅니다. 책 정보 열 15개 뒤에 `N 회차 읽은 기록` 4개 열이 동적으로 반복됩니다. 가져오기는 파일 전체를 검증하고 미리보기를 보여 준 뒤 한 번에 저장하며, 실패하면 기존 데이터를 유지합니다. ISBN만으로 존재하지 않는 표지 주소를 만들지 않으며, 가져온 뒤 `표지 자동 복구`에서 실제 이미지가 열리는 후보만 저장합니다. 빈 장르·출처는 태그·제목·저자·출판사 근거로 분류합니다. 앱 전용 장르·출처·컬렉션·시리즈는 Bookmory의 `사용 중인 태그들` 열에 표식으로 보존되어 왕복할 수 있습니다. JSON 전체 백업도 계속 지원합니다.

## 데이터 보호

- v2 IndexedDB `bookshelf-reading`의 `kv`, `drafts`가 authoritative 저장소입니다.
- 책·독서 회차·노트는 ID로 연결되며, 재독 이력과 기존 `note.takeaway` 값은 삭제하지 않습니다. takeaway는 새 편집 UI에서만 숨기고 JSON·Excel 내보내기에 보존합니다.
- 기존 `bookshelf.data.v1`은 최초 한 번 안전하게 이관합니다. 저장소 접근 또는 검증이 실패하면 빈 데이터로 덮어쓰지 않습니다.
- 설정의 `기존 기록 초기화`는 확인 문구를 입력해야 실행되며 책·독서 이력·노트·임시 초안을 한 번에 비웁니다. 실패하면 기존 상태를 유지하므로 초기화 전 JSON 백업을 권장합니다.
- 표지 복구는 국립중앙도서관 → 네이버 책 → 카카오 → Google Books → Open Library 후보를 사용합니다. ISBN이 정확히 일치하고 이미지 로딩에 성공한 표지만 원자적으로 저장하며 책 정보와 독서 기록은 변경하지 않습니다.
- 출처는 한국 / 일본 / 동양 / 영미 / 유럽 / 미분류 필드입니다. 자동 분류 결과는 책 정보에서 사용자가 수정할 수 있고, 예전 `서양` 값은 원문 메타데이터로 보존합니다.
- 브라우저 저장은 영구 백업이 아니므로 설정에서 정기적으로 전체 백업 파일을 보관하는 편이 안전합니다.

## 주요 소스

- `domain.js`: 모델 정규화·마이그레이션·검증·컬렉션·통계
- `repository.js`, `storage.js`: 원자적 IndexedDB 저장과 노트 충돌 보호
- `bookmory.js`: canonical XLSX 파싱·생성·회차 동적 처리
- `views-books.js`: 책꽂이·책장·컬렉션·통계
- `views-notes.js`: 노트 검색·자동 저장 편집기
- `views-settings.js`: 테마, Excel 가져오기·내보내기, JSON 백업
- `sw.js`: reading scope 전용 캐시
