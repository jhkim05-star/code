# 잔의 기록 1.2 — 가족 공용 OpenAI

독서앱처럼 와인·위스키의 라벨과 **그날의 경험**을 남기는 개인 서재입니다.

## 사용 흐름

가족은 처음 한 번 **가족 이용 코드 + 이 기기의 이름**만 입력합니다. ChatGPT 계정, AI 구독, 개인 API 키, 별도 비밀번호가 필요하지 않습니다. 운영자의 OpenAI API 키 **한 개를 서버에서만** 사용합니다. 가족에게 키를 나눠주는 방식이 아닙니다.

설정 → 가족 이용 승인 → AI 연결 확인 → 사진 선택 → 전송 동의 → 정리 결과 확인 → 저장.

- 컬렉션 / 노트 / 찾기 / 돌아보기 / 설정. 5가지 강조색과 3가지 배경.
- 같은 술의 여러 경험을 날짜·여행·장소·동행자·감상·평점·사진으로 따로 기록.
- 사진에서 인식한 원문은 보존하고 잘 모르는 날짜·빈티지를 임의 확정하지 않음.
- 여행·장소·이름·메모 검색, 수정, 백업, 오프라인 기록 보기는 AI 호출 없이 동작.
- 웹 평가는 해당 버튼을 눌렀을 때만 조회. 출처 없으면 저장하지 않음. 같은 제품·빈티지·숙성 정보의 결과는 서버에 30일 보관해 재사용.
- 실패·시간초과 시 입력 유지. 다른 모델·공급자로 자동 전환하거나 API를 자동 재시도하지 않음.

## 현재 코드와 실제 운영은 구분합니다

GitHub Pages에서는 기록·검색·사진 보관·JSON 백업·외부 AI 결과 가져오기가 가능합니다. **Pages만 배포하면 API 서버가 생기는 것은 아닙니다.** 공유 OpenAI 자동 분석은 아래 HTTPS Node 서버와 운영자 API 키 등록 후 사용할 수 있습니다.

키 존재 여부와 실제 응답 확인을 구분합니다. ‘AI 연결 확인’은 인증된 기기에서 짧은 OpenAI API 호출 1회를 보내고 응답이 완료됐을 때만 성공으로 표시합니다. 서버 테스트의 OpenAI 응답은 모의이며 실제 결제·모델 권한 검증을 대체하지 않습니다.

## 운영자가 한 번 설정할 항목

Node 22 이상, **단일 서버 인스턴스 + 영속 디스크**가 필요합니다. 기존 Railway 연결을 사용할 수 있지만 이 코드 변경만으로 서버 생성·요금제 업그레이드·API 결제를 하지는 않습니다.

| 환경변수 | 설정 |
|---|---|
| `OPENAI_API_KEY` | 이 앱 전용 OpenAI 프로젝트 API 키. 호스팅 서비스의 비공개 Variables/Secrets에만 입력 |
| `SIP_PUBLIC_ORIGIN` | 서버의 정확한 HTTPS 출처. 예: `https://your-app.example` (경로/마지막 슬래시 없음) |
| `SIP_MASTER_KEY` | 무작위 32바이트의 base64 값. 인증·사용량 파일 암호화용. 재배포 때 유지 |
| `SIP_FAMILY_CODE` | 무작위 24자 이상 가족 이용 코드. 키와는 다른 값. 가족에게만 전달 |
| `SIP_DATA_DIR` | 영속 볼륨 `/data/sip`. 웹 자산 폴더 밖, 실행 사용자 쓰기 권한 필요 |
| `HOST`, `PORT` | `0.0.0.0`과 호스팅 서비스의 포트 |

`OPENAI_MODEL` 기본값은 이미지 입력·구조화 출력·웹 검색을 지원하는 `gpt-5.4-mini-2026-03-17`입니다. 변경은 운영자 환경설정에서만 가능하고 클라이언트는 모델·프롬프트·도구를 지정할 수 없습니다. 분석 출력은 최대 6,000토큰, 웹 평가는 1,800토큰/검색 도구 최대 1회, 연결 확인은 32토큰으로 제한합니다.

암호화 키를 안전한 자신의 터미널에서 만드는 예: `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"`. 출력은 채팅이나 Git에 넣지 마세요. 가족 코드는 별도로 생성합니다. `.env.example`에는 값이 아닌 이름만 제공합니다.

Docker는 `sip/`을 빌드 컨텍스트로 사용합니다. `SIP_DATA_DIR` 볼륨의 소유자는 실행 계정(node, UID 1000)에 쓰기 권한이 있어야 합니다. 파일 저장 방식이므로 여러 복제 인스턴스나 여러 프로세스 실행은 지원하지 않습니다. 암호화 키나 디스크 분실은 로그인·사용량 상태의 분실로 이어집니다. 인증 파일 읽기 실패 때 자동 초기화하지 않습니다.

## 비용 보호 — 호출 수 상한이지 요금 보장이 아닙니다

| 범위 | 분석 + 연결 확인 | 웹 평가 |
|---|---:|---:|
| 기기별 하루 | 10회 | 3회 |
| 가족 전체 한 달 | 200회 | 30회 |

UTC 일자·월 기준이며 환경변수로 낮출 수 있습니다. 등록 기기는 기본 20개, 동시 API 요청은 기기당 1개·전체 2개입니다. 서버가 요청을 보내기 **전에** 사용량을 영속 저장합니다. 실패·시간초과가 과금됐을 가능성이 있어 차감한 횟수를 자동으로 돌려주지 않습니다. 동일 요청 ID는 다시 보내지 않고, 웹 캐시 조회는 새 AI 호출로 계산하지 않습니다.

이는 달러 기준의 결제 상한이 아닙니다. 사진 크기·입력/출력·추론·웹 검색에 따라 요금이 다르고, 이 서버 밖에서 같은 키를 쓰는 비용은 막지 못합니다. 운영자는 앱 전용 API 프로젝트의 과금 설정·한도·알림·자동충전을 별도로 확인해야 합니다. 한도를 초과해도 기록·검색은 계속 사용 가능합니다.

## 로그인 유지·보안·개인정보

- AI 공급자 OAuth·Google/Gemini 로그인·개인별 API 키 입력/등록 경로를 제거했습니다. 이전 `/api/login`, `/api/keys`, `/api/oauth/*`, `/api/disconnect`는 410으로 거부됩니다.
- 첫 승인 후 무작위 기기 토큰을 `HttpOnly; Secure; SameSite=Strict` 호스트 전용 쿠키에 둡니다. 서버에는 토큰 해시만 보관. 사용 중 세션 확인 시 90일(설정 가능)로 갱신하며 백그라운드 폴링은 하지 않습니다.
- 장기간 미사용, 쿠키 삭제, 브라우저 정책, 가족 코드 또는 `SIP_FAMILY_EPOCH` 변경 시 재승인이 필요합니다. 영구 로그인을 보장하지 않습니다.
- 이 기기 승인 해제는 AI 권한만 해제합니다. **로컬 노트를 지우거나 잠그지 않습니다.** 공유 기기는 별도 브라우저 프로필을 사용하세요.
- 승인 세션·사용량·공개 웹 평가 캐시는 `family-v1.enc`에 암호화합니다. 이전 `credentials.enc`는 읽거나 재사용·삭제하지 않습니다.
- 운영자 API 키는 환경변수에만 있습니다. 키/가족 코드/쿠키를 소스·로그·브라우저 저장소·JSON 백업에 넣지 않습니다.
- CSRF와 출처 검사, 전송 크기 제한, 인증 전 호출 거부, 서버 고정 프롬프트를 적용합니다. 제공자 오류 본문을 사용자에게 그대로 반환하지 않습니다.
- 사진은 선택한 최대 3장만, 노트는 15,000자까지만 전송합니다. 리사이즈한 이미지로 보내며 EXIF 위치정보를 포함하지 않습니다.
- 웹 평가는 제품명·생산자·빈티지·숙성·도수·캐스크만 전송합니다. 여행/동행자/개인 감상은 검색하지 않습니다.
- OpenAI API 기본 데이터 처리는 학습 사용과 로그 보관이 별개입니다. `store:false`를 무보관 보장으로 표현하지 않습니다.

## 기록은 계속 로컬 저장

시음 기록·사진은 기기별 IndexedDB `sip-journal`에 남습니다. AI 요청 처리 중에는 서버 메모리와 공급자에 전달하지만 이 서버의 인증 파일에 사진/노트를 저장하지 않습니다. 서버 캐시는 공개 제품 평가에만 사용합니다. 자동 동기화는 없습니다. 기존 JSON 형식과 기록은 유지하며 예전 `provider:gemini` 설정만 `openai`로 정규화합니다.

**기존 Pages 주소에서 서버 주소로 옮기면 브라우저 저장소가 달라집니다.** 기존 주소 설정에서 전체 백업(사진 포함) → 새 주소에서 가져오기로 이동하세요. 기존 사이트 데이터를 삭제하거나 기존 주소를 강제 이동시키지 않습니다.

설정의 **이 기기 기록 초기화**는 확인 문구를 입력한 경우에만 이 브라우저의 술 정보·시음 노트·초안을 비웁니다. 다른 기기의 기록과 가족 AI 승인은 건드리지 않습니다. JSON 백업의 **전체 교체**도 현재 기록을 교체하며, 초기화·교체 직전 열려 있던 다른 탭은 오래된 데이터를 다시 저장할 수 없습니다. 초기화가 취소되거나 저장소 쓰기에 실패하면 현재 기록은 유지됩니다.

개인 시음 노트는 공개 저장소와 정적 웹 자산에 넣지 않습니다. 사진에서 옮긴 기록을 사용하려면 별도로 받은 비공개 JSON 파일을 각 기기의 설정 → 백업 가져오기 → 전체 교체에서 직접 선택하세요. 다른 기기로 자동 동기화되지 않으며, 기존 기록을 보존하려면 교체 전에 백업하세요.

## 실행·검증

```sh
cd sip
npm start
# http://localhost:8134/sip/ (비밀설정 없으면 기록 전용 모드)
TZ=Asia/Seoul npm test
TZ=America/New_York npm test
npm run check
npm install --no-save --package-lock=false playwright@1.55.0
npx playwright install chromium
node tests/browser.mjs
```

브라우저 테스트는 실제 로컬 HTTP·쿠키·IndexedDB·서비스워커를 사용하고 **OpenAI 응답만 모의**합니다. 가족 승인·새로고침 유지·연결 확인·사진 전송 동의·미리보기·수동 저장·웹 캐시·한도 실패·취소 후 늦은 응답·오프라인 보존을 검사합니다. 테스트는 실제 iPhone Safari나 실제 유료 API 사용을 대신하지 않습니다.
